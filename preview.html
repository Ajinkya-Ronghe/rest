SOX Sentinel02
The use case

Privileged Access Monitoring for SOX-relevant systems

What the system learns

  • Normal login window and source IP
  • Usually accessed systems
  • Average session duration
  • Typical privilege behaviour
  • Approved ticket patterns

What the system flags

  • Off-hours privileged access
  • Unfamiliar financial system access
  • Abnormal session duration
  • Privilege escalation mid-session
  • No linked approval or ticket
